# Store policies

The Shopify connection used in this project cannot write legal policies (no `write_legal_policies` scope),
so paste these into **Shopify Admin > Settings > Policies** yourself. Once saved, the footer's Policies
column and the Help menu links (/policies/shipping-policy, /policies/refund-policy) pick them up automatically.

Review the wording before publishing. They are starting points, not legal advice.
